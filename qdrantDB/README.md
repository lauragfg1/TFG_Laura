# qdrantDB/

Directorio de trabajo de la instancia local de Qdrant. Está vacío a propósito: el binario
(`qdrant.exe`), el dashboard web (`static/`) y el estado de la base de datos (`storage/`) no se
versionan aquí — son un binario de terceros y estado regenerable, no código del TFG.

Para poblarlo, sigue la sección **"Configurar Qdrant"** del [README principal](../README.md).
