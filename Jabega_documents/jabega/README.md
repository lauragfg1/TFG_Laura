# Jabega_documents/jabega/

Esta carpeta está vacía a propósito: contiene el texto completo de 168 artículos científicos
del dominio SATCOM con copyright de sus editoriales, descargados vía acceso institucional de
la Biblioteca de la Universidad de Málaga, y no se distribuye en el repositorio público.

Para reproducir el corpus e indexarlo con `rag_indexer.py`, ver la nota **"Nota sobre
`Jabega_documents/`"** en el [README principal](../../README.md), sección "Preparar el RAG".
